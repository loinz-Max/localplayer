## P0 影响正常使用

### 1. 缩略图显示异常（主页卡片 + 播放列表抽屉）· ✅ 已修

截图现象：抽屉里的小缩略图比预留位置大一圈，**压住标题与时长文字**，蓝色选中框相对缩略图缩在里面；主页上 001/002/003 三张缩略图几乎是同一张空红底。

根因（三处叠加）：

| # | 位置 | 问题 |
|---|---|---|
| a | `Views/PlayerPanels.swift` `row()` | `ThumbnailView(...).frame(width: isLandscape ? 60 : 80)` **只给了宽，没给高**。`ThumbnailView` 内部是 `aspectRatio(16/9, .fit)`，在高度未约束的行里按自身理想尺寸撑开 → 溢出、盖住文字，蓝框按外层 frame 画所以错位 |
| b | `Services/ThumbnailLoader.swift` | 固定取第 5 秒。这批片源片头 5 秒还是台标/广告横幅，所以多张卡片长得一样，看起来像「坏图」 |
| c | `Views/Cards.swift` `ThumbnailView` | `scaledToFill` + 16:9 裁切。非 16:9 片源（竖屏、4:3）会被裁掉两侧 |

改法：
- 抽屉行改成 `.frame(width: 60, height: 34)`（横）/ `.frame(width: 80, height: 45)`（竖），`ThumbnailView` 内部 `.clipShape` 已生效，蓝框跟着同一个尺寸走。
- 取帧策略：取「时长 × 12%」，且不早于 3 秒；生成失败按 3s → 0s 逐级回落。缓存 key 加尺寸前缀，避免抽屉小图把网格大图挤掉。
- 非 16:9 片源：缩略图容器保持 16:9，图片用 `.scaledToFill` 但**只允许裁上下，不裁左右**（竖屏片源两边补黑），避免把主体裁没。

### 2. 导入后文件名被改成 `20261111_001` · ✅ 已修

根因：`Services/PhotoImporter.swift` 的 `nextName(in:)` 用「日期_流水号」重新命名，只有**相册导入**走这条路（文件 App / 爱思助手导入走 `LibraryStore.importURLs`，本来保留原名）。

改法：相册导入时用 `PHAssetResource.originalFilename` 拿原文件名（如 `IMG_0001.MOV`）；拿不到才回落到日期_流水号；重名由 `uniqueURL` 自动加 `-2`。

### 3. 倍速面板与倍速键同时显示 · ✅ 已修

截图现象：右下角「1×」圆键和弹出的速度面板同屏，两个都在。

根因：`PlayerScreen.bottomBar` 里 `speedButton` 无条件渲染，`speedPanelLayer` 是另一个 overlay。

改法：`speedOpen` 为真时隐藏倍速键（面板本身保留关闭入口：点面板外、再点一次键的位置、或选完档自动收）。

### 4. 长按 2× 的提示压在暂停键上 · ✅ 已修（按你的决定：暂停态不进 2×，提示改顶部居中小胶囊）

截图现象：「2× 快进」文字与图标叠在中部暂停圆键上，像两个图标糊在一起。

根因：
- `startLongPress()` 里 `flashHUD(...)` 走的中部 HUD 位置，和 `centerTransport` 同一处。
- `guard ... model.isPlaying ...` → 暂停状态下长按完全不响应，用户会以为功能坏了。

改法：
- 2× 提示改成顶部居中的小胶囊（在顶栏下方 44pt），不碰中部按钮；松手立即消失。
- 暂停时长按也生效：进入 2× 并自动续播，松手恢复原倍速与原暂停态。

### 5. 快进/倒退 10 秒不需要提示弹窗 · ✅ 已修

根因：`PlayerScreen` 双击手势（`doubleTapGesture`）与两个 ±10 按钮都调 `flashHUD(...)`。

改法：删掉这三处 HUD，只保留实际跳转。HUD 组件保留给音量/亮度用。

## P1 观感与缺失功能

### 6. 按钮透明度不够（顶栏关闭/列表、倍速键、进度条胶囊）· ✅ 已修

现象：播放页顶栏两个 38 圆键在亮画面上几乎看不见，图标对比度不足。

根因：`Support/Glass.swift` 的 `.control` 预设是**白色染色**（白 13% → 5%），在亮画面上等于加亮，白图标失去对比。

改法：`.control` 改成暗色染色（黑 34% → 46%）+ 描边保持上沿亮光；`.subtle`（进度条胶囊）同步压暗一点。资料库页深色底上不受影响，只动播放页用到的两档。

### 7. 空库不该出现「相册 / 文件」两个大按钮 · ✅ 已修

根因：`LibraryView.emptyState` 里按钮区无条件渲染。

改法：`library.allItems.isEmpty` 时只留图标 + 「还没有视频」+ 「点右上角导入」一行说明；有内容但当前目录为空时保留按钮（那时用户是站在子文件夹里）。

### 8. 方向锁定（新增功能）· ⏸ 暂缓（你说先不动）

现状：`Info.plist` 允许竖屏 + 左右横屏，App 内没有任何锁定入口；`HANDOVER` 第 7 节第 3 条也一直挂着。

改法：
- `AppSettings` 加 `orientationLock`（auto / portrait / landscape）。
- 新增 `OrientationLock` 单例 + `AppDelegate.supportedInterfaceOrientationsFor` 返回当前允许的方向。
- 改设置后用 `requestGeometryUpdate`（iOS 16+）立即转过去；iPad 同样适用。
- 设置页「播放界面」分组加一行三选一（自动 / 锁定竖屏 / 锁定横屏）。
