# 幕间 · 设计说明 v0.5

> 前一版（v0.2）作废：那版还在讲「继续观看」「搜索」「网格⇄列表切换」「画中画」「音轨」，这些功能在 v0.3 已整体删除。
> **以代码为准。** 本文的数值是照着 `Support/Glass.swift`、`Support/Palette.swift` 和实际视图抄下来的；`preview/` 里的原型只用来回顾设计意图，已经落后于实现（见第 8 节）。

---

## 1. 定位

一个人用的 iOS 本地视频播放器（iPhone / iPad），不上架、不联网、无账号、零第三方依赖。

| 项目 | 决定 |
|---|---|
| 播放内核 | **AVPlayer**（mp4 / mov / m4v / 3gp / mpg / mpeg） |
| 片源 | **仅本地文件**：文件 App 导入、相册导入、访达文件共享 |
| 视觉基调 | 近黑底 + 自定义暗色玻璃，Outplayer 式极简，不做海报墙刮削 |
| 目标 | 取代手机里现有播放器，日常能一直用下去 |

### 2.2 玻璃配方（`Support/Glass.swift`）

**四层玻璃**（现用配方，深色界面下的稳定观感）：

1. `.ultraThinMaterial` —— 真实背景模糊
2. 线性渐变染色（顶部亮、底部暗）
3. 0.75pt 渐变描边（上沿亮、下沿几乎看不见）
4. 外投影（让整块浮起来）

| 预设 | 染色 top→bottom | 描边 top→bottom | 投影 | 用在哪 |
|---|---|---|---|---|
| `.control` | 白 9.5% → 2.8% | 白 30% → 5% | r12 / y4 / 26% | 圆键、运输胶囊、进度条胶囊 |
| `.panel` | 黑 21% → 31% | 白 26% → 4% | r28 / y10 / 40% | 菜单、抽屉、错误卡片 |
| `.stage` | 黑 25% → 35% | 白 30% → 5% | r12 / y4 / 32% | 播放页控件（压视频画面） |
| `.hud` | 黑 22% → 32% | 白 32% → 6% | r18 / y6 / 34% | toast、长按倍速、导入进度 |

> **透明度的两个约束**（都是踩过的坑）：
> 1. 染色 alpha 压低 → 更透，但控件和画面之间会失去边界，描边必须同步加亮（约 +0.04）。只降染色不加描边，控件会散在画面里。
> 2. **纯黑背景上玻璃永远是黑的** —— 下面没有东西可透，材质再透也看不出层次。资料库背景顶部特意压了一层 2.8% 的白雾（`LibraryView.backgroundLayer`），就是为了给材质一点可模糊的底色。实测这一步比改 alpha 有效得多。

> 试过 "白色液态玻璃"（Material + `colorScheme: .light` + 高白染色），在纯黑背景上会退化成灰块或白塑料，已回滚。深色界面下这套四层是目前最稳的。

> **不用原生 `glassEffect`**：那是 iOS 26 SDK 才有的 API，CI 跑在 `macos-15`（Xcode 16）上编不过；上面四层在 iOS 17+ 上能还原同样的液态玻璃观感，部署目标保持 iOS 17。

### 2.4 品牌与图标

| 项 | 规格 |
|---|---|
| 中文名 | **幕间** |
| 英文名 | **Interlude**（关于页作小字副标，字距略放开） |
| 桌面显示名 | `Info.plist` → `CFBundleDisplayName` = 幕间（工程名、bundle id 不动） |
| 图标 | 深底 `#0A0A0B` 上一枚圆角三角形的液态玻璃，玻璃厚、边缘有青紫色散与高光；主体占画布约 62%，居中 |
| 文件 | `Assets.xcassets/AppIcon.appiconset/icon-1024.png`，1024×1024，**无 alpha**，单尺寸即可 |
| 圆角 | 不要自己画，系统会裁（约 22.37%），自己画会变成圆角套圆角 |

**为什么叫幕间**：它是两幕之间灯暗下来的那段空白，也正是「暂停时留下的那一帧」。图标不画播放三角（全行业最泛滥的符号），而是让「一束光在玻璃里被折成影像」来承担这层意思。

**换图流程**

1. 出图 1024×1024、RGB 无 alpha，主体居中且不小于画布的 55%——主屏上只有 60pt，细节全丢，只能靠轮廓和明暗关系辨认。
2. 直接覆盖 `icon-1024.png`（不用生成多尺寸，Xcode 会缩）。
3. push → CI 出包 → 覆盖安装 → **重启手机**。iOS 会缓存桌面图标，不重启可能还显示旧的；不要用卸载解决，卸载会清空 `Documents`。

**已知待改进**：现在这版是「空心玻璃三角」，60pt 下视觉重量偏轻，和实底图标并排会被压住。若要重做，走「实心三棱柱 + 一条胶片状光带」的局部修正，别整张重生成。

## 3. 信息架构

```
资料库（根目录）
 ├─ 文件夹卡片（有子目录才出现，排在视频前）
 └─ 视频卡片（双列网格）
      └─ 播放页（同层 overlay 全屏覆盖，不是 modal）
            ├─ 播放列表抽屉（右侧）
            └─ 倍速浮层（右下角，贴倍速键上方）
设置（sheet）
 ├─ 播放
 ├─ 播放界面（屏幕常亮 / 自动隐藏 / 启动时锁定）
 ├─ 存储
 └─ 关于
```

两个层级，没有 Tab 栏、没有侧边栏——文件多时用文件夹分；跨文件夹找文件用顶栏搜索。

## 4. 页面规格

### 4.1 资料库

**顶栏**（左→右）：搜索（`magnifyingglass`）｜设置（`gearshape`）｜标题｜导入（`arrow.down.doc`）｜更多（`ellipsis`）。

标题**不放在 `HStack` 里**：它和按钮是两个层叠的层，标题单独居中。这样两侧按钮数量变化（进多选、以后增减）都不会让它偏移。

标题文案：根目录 `Interlude`，子目录显示文件夹名，多选态显示「已选 N 个」。进入子目录后顶栏下方出现 `‹ Interlude` 面包屑。

**搜索态**：点搜索键后顶栏整体换成一个圆角输入框 + 右侧「取消」，标题暂时让位；同时在弹输入法。搜索范围是**整个资料库**（不是当前目录），结果卡片副标题前置所在文件夹名（根目录写「根目录」）。未输入时显示提示态，无结果时显示「没有匹配的视频」。搜索期间面包屑隐藏，因为结果跨目录。

**网格**：文件夹卡片在前，视频按当前排序在后。文件夹卡片 = 16:9 玻璃底 + 蓝色文件夹图标 + 名称（可自定义显示名）+ `N 个视频`（含子目录递归计数）。

**视频卡片**：缩略图（16:9）+ 右下角标（看完打勾 / 看一半显示百分比）+ 缩略图底部 3pt 进度线 + 标题 + `时长 · 体积`。标记已看后进度线与百分比一起消失。副标题只有 `时长 · 体积`——百分比已经在角标上了，正文不再重复；列表视图没有角标，所以在副标题里保留「已看 N%」。

**长按菜单**（`CardMenu`）
- 触发：长按 0.38s；同一串手势里的点击被 `menuGuard`（0.35s）屏蔽，避免菜单刚弹出就被关掉
- 锚点：被长按卡片的左下角，向下偏移 8；若下方放不下则翻到卡片上方；左右夹在 16pt 边距内
- 遮罩：黑 38%；被长按的那张**原位留空、重画一份浮在遮罩之上**：放大 **1.09**、加一圈 1pt 白 28% 亮边、再叠一层散投影（`y 12 / blur 22 / 55%`）。
  动画从原尺寸弹出（弹簧 0.30 / 0.86），读作「这张被拎起来了」。
  亮边是必须的——近黑底上黑影几乎看不见，只有亮边和放大能传达「被选中」。
  菜单锚点按**放大后的边缘**让位（`liftedRect`），否则会贴在浮起的卡片上。
- 内容：一行文件名（中间截断）→ 标记已看/未看、重命名、移到文件夹 → 分隔线 → 删除（红色单独一组）

**文件夹长按菜单**（`FolderMenu`）
- 同一套锚定规则，宽 174、行高 42；文件夹卡片同样原位留空 + 放大 1.09 + 亮边，浮起时底色 6%→14%、描边 8%→28%
- 内容：文件夹名 → 重命名、删除文件夹（红色）
- **重命名只改显示名**：磁盘目录名不变，所以里面视频的 id（相对路径）与进度记录都不受影响。显示名存在 `folder.displayNames.v1`
- **删除文件夹**：递归删除整个目录，先把里面每个视频的进度/已看记录清掉，再删目录；确认弹窗里写明会删掉多少个视频

**导入菜单**：从相册导入 / 从文件导入（白色圆底图标 + 深色符号）。
**更多菜单**：全选 → 创建文件夹 → 分隔线 → 网格 / 列表（当前项打勾）→ 分隔线 → 名称 / 日期。
排序键实际有四档（最近播放 / 名称 / 添加日期 / 文件大小），但菜单只露名称与日期两个入口；
已经按名称排序时点一下就是升/降切换，标题显示「名称 ↑ / 名称 ↓」。

**移到文件夹**（`MoveFolderSheet`）：列出根目录与所有文件夹（按层级缩进），当前所在目录显示「当前」并禁用；选中后移动文件，并把进度与已看标记迁到新的 id。

**空状态**：只有文字，没有卡片框、图标和按钮。根目录显示「还没有视频 / 点右上角的导入按钮」；
子文件夹显示「这个文件夹里还没有视频 / 导入的视频会放进这个文件夹」。

**导入进度**：底部胶囊（与 toast 同位置），一行「正在导入 3/8」+ 2.5pt 细条。
不铺遮罩，导入期间照样能滑动、能点开别的视频。导完的汇总提示接在同一位置：
「导入 8 个，2 个同名已改名，1 个失败」。

### 4.2 播放页

> 播放页里只剩六样东西：**关闭（左上）/ 列表（右上）/ 三圆（正中）/ 进度条（底部通栏）/
> 锁定（左下）/ 倍速（右下）**。设置类的东西全部搬进 SettingsView，播放页不再有设置抽屉。

**显隐规则**
- 单击画面：显隐控件；播放中按设置里的自动隐藏时长淡出，暂停时常驻
- 列表抽屉展开时：顶部按钮、三圆、进度条**全部不渲染**，只剩画面 + 抽屉 + 28% 遮罩
- 倍速面板是浮层，展开时不收起控件（它只占右下角一小块）
- 任意拖动/双击会重新计时

**顶部**
- 左上关闭、右上列表，都是 38 圆键、玻璃 `control`；左右内边距 20、上边距竖屏 6 / 横屏 12

**中部三圆（`centerTransport`）**
- 尺寸等大：竖屏 58、横屏 62；间距竖屏 26 / 横屏 30
- 图标区分职能：−10s 25、播放/暂停 24、+10s 25（横屏统一 26/27）
- 竖直居中（屏高 50%），横屏时位置不动

**底部**
- 倍速键：44 圆键，显示当前倍数（`1×` / `1.5×`），右对齐
- 锁定键：44 圆键，锁图标，左下角，与倍速键对称（详见下方「防误触」）
- 进度条：36 高、圆角 18 的**通栏胶囊**，内部左右是时间文字、中间是轨道（4pt 轨道 + 11pt 白色滑块）
  - 左侧已播 `00:14`，右侧 `-45:11`，都用等宽数字
  - 拖动时进度条跟手走，上方弹出预览小窗（见「拖动预览」）
- 内边距：竖屏 20 / 底 26；横屏 16 / 底 16

**倍速面板（`SpeedPanel`）**
- 浮在倍速键上方 8pt，右缘与倍速键对齐；宽度按内容自适应（竖屏约 110、横屏约 116），圆角 18
- 五档：2 / 1.5 / 1.25 / 1 / 0.5，行高 34、字号 13.5，当前档位左侧一个 11pt 勾
- 面板只有「标题 + 五档」，所以做窄：竖屏只占右侧约 28% 宽度，画面中部与三圆不被遮挡
- 选中即关闭；点画面空白、开始拖动、开列表抽屉也都会关掉

**列表抽屉（`QueuePanel`）**
- 竖屏宽 264、横屏宽 320；圆角 28；右侧留 12、上下留 12；内边距竖屏 16 / 横屏 18
- 正在播放标题 + 副行（时长 · 体积）+ `第 N 个 · 共 M 个` + 列表（当前项蓝框 + 波形图标）
- 入场：从右侧滑入 + 淡入（0.22s easeOut）

**防误触（左下角手动锁）**
- 播放页左下角 44pt 圆键，与右下角倍速键对称；点一下锁上，锁上后立刻收起抽屉 / 倍速面板与控件
- 锁定时铺一层全屏触摸拦截：单击 / 双击 / 滑动一律不响应
- 锁上后点屏幕，只在左下角亮出解锁键（同一位置、锁形图标），3 秒后自动收回；点它解锁
- 没有任何长按手势 —— 长按已经给了倍速，再叠一个「长按解锁」必然撞车
- 解锁后控件重新出现，按自动隐藏时长重新计时

**拖动预览**
- 进度条拖动和画面横滑共用一套：底部进度条跟手，上方弹出目标帧小窗
- 小窗 168 宽（横屏 148），圆角 10，白 0.18 描边，下方挂目标时间胶囊；距底 94pt（横屏 78）
- 抓帧走 `ScrubPreviewer`：0.5 秒一档缓存，同一时刻只跑一个任务，松手才真正 seek

**自动隐藏时长**：2 / 4 / 6 秒，存 `AppSettings.autoHideDelay`

**手势**

| 手势 | 行为 |
|---|---|
| 横滑 | 调进度，跟手；跨度 `min(max(总长×0.4, 60), 240)` 秒，松手 seek |
| 左半屏竖滑 | 屏幕亮度 |
| 右半屏竖滑 | 系统音量 |
| 长按 0.28s | 临时加速到设置里的「长按倍速」（1.5 / 2 / 2.5 / 3），松手复位；暂停态不触发；手指移动超过 12pt 立刻退出加速、转进 seek |
| 双击左/右 35% | ∓10 秒 |
| 单击 | 显隐控件（倍速面板开着时先关面板） |
| 双指捏合 | 放大→填充，缩小→适应 |

**轻提示（统一在 `Support/HUD.swift`）**

| 用途 | 规格 |
|---|---|
| `HUDLabel` | 胶囊 + 可选 10.5pt 图标 + 13pt 主文案 + 次级小字；数字等宽，2× 变 10× 不会左右跳 |
| toast | 资料库距底 28、播放页距底 120；都用 `HUDLabel` |
| 长按倍速 | `» 2× 快进`，水平居中，距顶 58（竖屏）/ 52（横屏） |
| 亮度 / 音量 | 屏幕顶部居中 180×4 细条，无图标无数字；0.5pt 描边 + 柔投影 |
| 导入进度 | `ImportProgressHUD`：166 宽、「正在导入 3/8」+ 2.5pt 细条 |
| 转屏幕布 | `OrientationCurtain`：全屏 94% 黑幕 + 转向小手机弹簧动画 + 「竖屏观看 / 横屏观看」；只在**确实会转屏**时出现，全程约 0.9 秒，期间拦截触摸 |

**结束行为**
- 单集循环：回 0 继续，不算看完
- 列表循环：标记已看 → 播下一个，到底回第一个
- 播完暂停：标记已看、暂停并常驻控件；中间键变成重播图标（`arrow.counterclockwise`），点一下回 0 重播
- 播完后条目**仍留在「最近播放」里**（只清进度，不动顺序）

### 4.3 设置页

四级菜单（`SettingsPage` + `NavigationStack`），一级页只有图标 + 名称 + 箭头，**右侧不再显示状态摘要**（`长按 2× · 续播开` 这类），避免一行里两种信息互相抢。

| 一级 | 项 |
|---|---|
| 播放 | 断点续播、长按倍速（1.5 / 2 / 2.5 / 3）、默认播放模式（三选一） |
| 播放界面 | 默认画面（适应 / 填充 / 拉伸）、控件自动隐藏（2 / 4 / 6 秒）、播放页方向（跟随系统 / 竖屏 / 横屏）、屏幕常亮 |
| 存储 | 视频占用、视频数量、清理缩略图缓存 |
| 关于 | 版本号（只显示 `0.0.2`，不带括号里的构建号）、不联网 / 不上传说明 |

二级页自绘返回键，系统导航栏隐藏（`toolbar(.hidden)`）。
「播放界面」里的几项原来在播放页抽屉里，统一收到这里之后播放页不再有设置抽屉。

## 5. 交互决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 倍速/模式的生效范围 | 只在本次播放 | 存在 `PlayerScreen` 层，切集不丢、退出即丢，避免「上次调快了忘了改回来」 |
| 视频重命名 | 改磁盘文件名，扩展名保留 | 文件名 = ID，改名后自动迁移进度与已看标记；同名会失败并提示 |
| 文件夹重命名 | **只改显示名**，磁盘目录名不动 | 改目录名会让里面所有视频的 id 全部变化，进度/已看/排序记录都要重写，风险不对等 |
| 防误触怎么触发 | 播放页左下角圆键 | 原来的「设置里预设启动时锁定」用过一轮：进页面就锁、解锁要长按，既容易误锁，又和长按倍速撞车 |
| 防误触的解除方式 | 点亮出来的解锁键 | 锁定时点屏幕不做任何事，只把同一位置的解锁键亮出来；不用长按，避免与倍速手势冲突 |
| 长按菜单宽度 | = 卡片宽度（174） | 视觉上像从卡片长出来的 |
| 抽屉展开时 | 整层控件不渲染 | 避免控件与抽屉抢空间，画面更完整 |
| 倍速面板展开时 | 控件照常显示 | 面板只有一列档位，宽度按内容自适应，不需要为它让出整片画面 |
| 进度条 | 竖横屏都是底部通栏胶囊 | 时间放进胶囊里，两端对齐；比竖屏「无底贴边」更好按，也不用两套布局 |
| 播放设置放哪 | 全部搬进 App 设置页 | 播放页只留「看片时要摸的东西」；默认值本来就不该在播放中改 |
| 抓帧存相册 | 从播放页移除 | 参考图没有这个槽位，自用频率也低；`FrameGrabber` 与相册写权限整套删掉了，别再加回来 |
| 不支持格式 | 仍显示在列表，带警告图标 | 用户能看见「文件在」，点开才提示转码 |
| 画中画 / 音轨 / 字幕 | 全部删除 | 自用场景用不到，删掉换来少 4 个文件与一条权限 |
| 转屏的观感 | 拉黑幕遮住旋转动画 | 「跟随系统」下退出播放页会被强制转回竖屏，系统那次旋转动画很突兀。转屏前先拉起 94% 黑幕，旋转发生在幕布后面，幕布中央一枚小手机转向 + 方向文字——正好是「幕间」换幕时灯暗一下的本义。只在真的会转屏时出现（横握手机退出 / 设置成横屏进入），否则完全不闪 |

## 6. 数据与状态

- **播放进度**：`relativePath → 秒`，UserDefaults 单键快照；尾部 `min(15 秒, 总长 25%)` 视为看完、清掉进度并标记已看
- **最近播放**：最多 60 条，用于「最近播放」排序
- **已看标记**：手动标记的集合，标记时顺手清掉进度；播完也会自动写入（单集循环除外）
- **文件夹显示名**：`相对路径 → 自定义名`，存 `folder.displayNames.v1`；路径本身永不改变
- **缩略图**：NSCache（内存），取「时长 12%，不早于 3 秒」那一帧（避开片头台标与广告）→ 失败退 3 秒 → 首帧 → 占位图标；时长单独缓存
- **设置**：UserDefaults 直读直写，键名集中在 `AppSettings.Key`

## 7. 已知边界

1. MKV / AVI / WMV 等系统解码器不支持的容器播不了；换 mpv 只需替换 `PlayerModel` 与 `VideoSurface`。
2. `ts` / `m2ts` 不列为可播（AVPlayer 只在 HLS 分片里认 MPEG-TS）。
3. 不做字幕、画中画、音轨、局域网传输、海报墙。
4. 相册导入拿到的是导出版本；iCloud 优化存储的原片需先下载。

## 8. 原型与实现的关系

**代码是唯一真相。** 两个原型是设计阶段的产物，已经落后于实现：

| 原型 | 现在的情况 |
|---|---|
| `preview/ui-v3.html` | 浅色玻璃、带框空状态、三项长按菜单，这些都已过时；资料库的布局骨架仍有参考价值 |
| `preview/ui-v5-player.html` | 播放页版式（顶栏 / 三圆 / 通栏进度条 / 窄倍速面板）与实现一致，但缺左下角锁定键 |
| `preview/ui-preview.html` | 最早的初版，仅存档，不要参考 |

要确认某个界面到底长什么样，看 `ci-shots` 分支的模拟器实拍图，比原型准。
改界面直接改 `Views/` 与 `GlassStyle` / `Palette`，不必回头同步原型；将来若要整体重设计，再一次性重画。
